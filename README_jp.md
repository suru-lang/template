# 雛形(する のテンプレートエンジン)

日本語プログラミング言語 [する](https://github.com/suru-lang/suru) の、Jinja2 のようなテンプレートエンジンです。する だけで書いてあり、C のライブラリは要りません。テンプレートの文字列を読み、値を差し込んで文字列を返します。たとえば [suru-lang/http](https://github.com/suru-lang/http) で作る Web アプリの HTML の画面に使えます。

計画は [#1](https://github.com/suru-lang/template/issues/1) です。この版は差し込み・注釈・繰り返し・条件・式・フィルターまでで、継承・自動エスケープはこれから足します。

## 入れ方

[kumu](https://github.com/suru-lang/suru/blob/main/README_jp.md#プロジェクトを組むkumu) のプロジェクトで:

```sh
kumu 追加 github.com/suru-lang/template
```

## 使い方

```
「JSON」 を 読み込んで 使う
「雛形」 を 読み込んで 使う

挨拶表示する とは 手順
  値 とは 「{"客": {"名前": "花子"}, "品々": [{"名前": "りんご", "値段": 120}, {"名前": "みかん", "値段": 80}]}」 を JSON読取した 結果
  雛 とは 「{{ 客 の 名前 }}さん、いらっしゃいませ。今日のおすすめは{{ 品々 の 1番目 の 名前 }}({{ 品々.1.値段 }}円)です。」
  r とは 雛 を 値 で 雛形描画する
  もし r が
    s の 成功 ならば s を 表示する
    e の 失敗 ならば 「描画できません: 」 + e を 表示する

挨拶表示する
```

「花子さん、いらっしゃいませ。今日のおすすめはりんご(120円)です。」と表示します。例は [例/挨拶.suru](例/挨拶.suru) です。`「雛形」 を 読み込む` なら、`雛形内の雛形描画する` のように前置きを付けます。

| 呼び方 | 結果 |
|---|---|
| `t を 値 で 雛形描画する` | テンプレートの文字列 `t` に `値`(`JSON物`)の値を差し込んだ文字列。`（文字列 と 文字列） の 成否` |
| `t を 雛形解析する` | テンプレートを1回だけ読む。`（雛形 と 文字列） の 成否` |
| `g を 値 で 雛形適用する` | 読んだテンプレートに値を差し込む(同じものを何度も描くとき)。`（文字列 と 文字列） の 成否` |
| `t を 値 で 設定 に 雛形設定描画する` ・ `g を 値 で 設定 に 雛形設定適用する` | 設定(`雛形既定設定` と、それに足したもの)を使って同じことをする |
| `設定 に 名前 と 関数 を 雛形濾過追加する` | 自分のフィルターを足した設定(下を見てください) |

テンプレートの書き方です。

| 書き方 | 意味 |
|---|---|
| `{{ 題 }}` | 名前 題 の値 |
| `{{ 客 の 名前 }}` ・ `{{ 客.名前 }}` | 客 のフィールド 名前 |
| `{{ 品々 の 2番目 }}` ・ `{{ 品々 の 2 }}` ・ `{{ 品々.2 }}` | 品々 の2番目の要素(位置は1から) |
| `{{ 「文字」 }}` ・ `{{ 3 }}` | 文字列や数をそのまま |
| `{# … #}` | 注釈(何も書かない) |
| `{% 品々 の それぞれ を 品 として %}` … `{% 以上 %}` | 品々 の要素ごとに繰り返す(`{% for 品 in 品々 %}` … `{% endfor %}`) |
| `{% 値段表 の それぞれ を 名 と 値 として %}` | 物の名前と値ごとに繰り返す(`{% for 名, 値 in 値段表 %}`) |
| `{% 空なら %}` | 繰り返しの中で、繰り返すものが無いときに書くもの(`{% else %}`) |
| `{{ 繰り返し の 番号 }}` | 繰り返しの中の、繰り返しの値(決めたことを見てください) |
| `{% もし 在庫 > 0 ならば %}` … `{% そうでなく もし 予約可 ならば %}` … `{% そうでなければ %}` … `{% 以上 %}` | 条件(`{% if 在庫 > 0 %}` … `{% elif 予約可 %}` … `{% else %}` … `{% endif %}`) |
| `{{ 値段 * 2 + 1 }}` ・ `{{ 名 + 「さん」 }}` | 式(決めたことを見てください) |
| `{{ 名 を 空白除去して 大文字にする }}` ・ `{{ 名 \| trim \| upper }}` | フィルター(下の表) |

フィルターです(どれも する の書き方と Jinja の書き方で書けます)。

| する | Jinja | 結果 |
|---|---|---|
| `x を 大文字にする` ・ `小文字にする` | `x \| upper` ・ `lower` | 大文字・小文字 |
| `x を 空白除去する` | `x \| trim` | 両端の空白を除いたもの |
| `x を 長さにする` | `x \| length`(`count`) | 文字列・リスト・物の長さ |
| `xs を 「、」 で 結合する` | `xs \| join("、")` | 要素をつないだもの |
| `s を 「,」 で 分割する` | `s \| split(",")` | 文字列のリスト |
| `s を 「a」 から 「b」 へ 置換する` | `s \| replace("a", "b")` | 「a」を「b」にしたもの |
| `x を 「なし」 で 既定にする` | `x \| default("なし")`(`d`) | x が無いか `無` なら「なし」 |
| `x を 逃避する` | `x \| escape`(`e`) | HTML の逃がし(`& < > " '`) |
| `xs を 整列する` ・ `逆順にする` | `xs \| sort` ・ `reverse` | 小さい順(数だけか文字列だけ)・逆の順 |
| `xs を 先頭にする` ・ `最後にする` | `xs \| first` ・ `last` | 最初・最後の要素(空なら `無`) |
| `x を 数値にする` ・ `整数にする` ・ `切捨する` | `x \| float` ・ `int` | 数(数か文字列から) |
| `x を 四捨五入する` | `x \| round` ・ `round(2)` | 四捨五入(小数第2位まで) |
| `x を 桁区切する` | | 「1,234,567」 |
| `x を 文字列化する` ・ `JSON文字列にする` | `x \| string` ・ `tojson` | `{{ }}` で書くときの文字列、JSON |

自分のフィルターは設定に足します。

```
「JSON」 を 読み込んで 使う
「雛形」 を 読み込んで 使う

JSON の リスト を 二倍濾過する は （JSON と 文字列） の 成否
xs を 二倍濾過する とは
  もし xs の 先頭 が
    （n の JSON数） ならば （（n * 2） の JSON数） の 成功
    そうでなければ 「数ではありません」 の 失敗

二倍表示する とは 手順
  設定 とは 雛形既定設定 に 「二倍する」 と 二倍濾過すること を 雛形濾過追加する
  値 とは 「{"数": 21}」 を JSON読取した 結果
  （「{{ 数 を 二倍する }}・{{ 数 | 二倍する }}です」 を 値 で 設定 に 雛形設定描画する） を 表示する

二倍表示する
```

## 決めたこと

1. **区切りは Jinja と同じ。** `{{ … }}` は値を書き、`{% … %}` は命令、`{# … #}` は注釈です。命令の言葉は日本語にし、Jinja の英語の言葉も別名として使えるようにします(`{% 品々 の それぞれ を 品 として %}` と `{% for 品 in 品々 %}`)。
2. **値は標準の `JSON`。** 差し込む値は `lib/JSON.suru` の `JSON物` なので、JSON のファイルから読んだものや HTTP で受け取ったものをそのまま渡せます。その項目が、テンプレートで使える名前です。
3. **描画は 成否 を返す純粋な関数。** テンプレートを読めないときや値が無いときは、「2行目: 「客」に「年」がありません」のように行の付いた `失敗` になります。`した 中身` で失敗をそのまま返せます。
4. **無い名前はエラー。** 定義されていない名前を何も書かない Jinja と違い、無い名前やフィールドはエラーにして、打ち間違いが見つかるようにします。無くてもよい値は、既定の値のフィルターで書けるようにします。
5. **値の書き方。** 文字列はそのまま、数は `文字列化する` と同じ(`120`・`80.5`)、真偽は `真`・`偽`、`JSON無` は何も書かず、リストと物は1行の JSON にします。
6. **「の」と「.」は同じ。** `客 の 名前` は する のフィールドの読み方、`客.名前` は Jinja の書き方です。その後の数や「N番目」は位置で、する の標準ライブラリと同じく1から数えます。
7. **文字列の中の閉じは数えない。** `{{ 「}}」 }}` の「」の中の 「}}」 は文字列の一部です。文字列の中の「」は、する と同じく入れ子として数えます。

8. **繰り返しは する と同じく読む。** `{% 品々 の それぞれ を 品 として %}` は する の `の それぞれ` の形で、`{% for 品 in 品々 %}` も同じです。`{% 以上 %}`(`{% 以上です %}`・`{% endfor %}` も)で終わります。付けた名前は繰り返しの中だけで見え、外の同じ名前を隠します。
9. **物は書いた順に繰り返す。** 名前を2つ書くと(`名 と 値 として`・`for 名, 値 in …`)、それぞれの項目の名前と値です。1つなら Jinja と同じく名前だけです。リストには名前を1つ書きます。
10. **繰り返しの値。** 繰り返しの中では `繰り返し`(`loop` も)に、`番号`(1から)・`長さ`・`最初である`・`最後である`・`残数`(残りの数)と、Jinja の `index`・`index0`・`length`・`first`・`last`・`revindex` があります。入れ子のときは一番内側の繰り返しのものです。
11. **空のとき。** 繰り返しの中の `{% 空なら %}`(`{% else %}` も)から後ろが、リストや物が空のときに書くものです。

12. **条件は する と同じく読む。** `{% もし 条件 ならば %}`・`{% そうでなく もし 条件 ならば %}`・`{% そうでなければ %}` は する の言葉で、`if`・`elif`・`else` も同じです。`{% 以上 %}`(`{% endif %}` も)で終わります。
13. **真になるものは Jinja と同じ。** `無`・`偽`・`0`・「」・空のリスト・空の物は偽で、ほかは真です。
14. **条件の中では無い名前は 無。** 条件の中では、無い名前・フィールド・位置はエラーにせず `無` にするので、`{% もし 客.住所 ならば %}` で有るかどうかを確かめられます。条件の外ではこれまでどおりエラーです。
15. **式。** 弱いものから順に、`または`・`or`、`かつ`・`and`、`not x` と `x でない`、比べる `=` `==` `が` `≠` `!=` `<` `>` `<=` `>=` `≦` `≧`(1つの式に1回)、`+` `-`、`*` `/` `%`、符号の `-` です。`( )` と `（ ）` でまとめます。`+` は数を足し、文字列をつなぎます。`<` などは数どうしと文字列どうしを比べます。ほかの組み合わせはエラーです。`真`・`偽`・`空`(空のリスト)・`無`(`true`・`false`・`null`・`none` も)は値です。

16. **フィルターは する の関数と同じく呼ぶ。** `{{ s を 「a」 から 「b」 へ 置換して 大文字にする }}` のように、値を「を」で、引数を助詞で(順は自由)渡し、「して」でつなぎます。呼び出しは式の中で一番弱いので、`{{ 「ab」 + 名 を 空白除去する }}` はつないだ文字列の空白を除きます。Jinja の `|` は Jinja と同じく強く結びつくので、`{{ 品々 | length > 2 }}` は長さを比べます。Jinja のフィルターの名前は する の名前になります。
17. **`既定にする` は無い名前も見る。** `既定にする`・`default` に渡す値は条件の中と同じく読むので、無い名前やフィールドはエラーでなく既定の値になります。
18. **自分のフィルターは する の関数。** `雛形濾過追加する` で足したフィルターは、値と引数のリスト(引数は で・から・へ・に・より の順か、`|` の後に書いた順)を受け取り、`値 の 成功` か `理由 の 失敗` を返します。失敗は行の付いたエラーになります。する の書き方で呼ぶには名前を「する」で終わらせます。`|` の後ならどんな名前でも使えます。
19. **Jinja の引用符の文字列。** テンプレートでは「…」のほか、Jinja の書き方のために `"…"`・`'…'` も書けます。
