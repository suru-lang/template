# 雛形(する のテンプレートエンジン)

日本語プログラミング言語 [する](https://github.com/suru-lang/suru) の、Jinja2 のようなテンプレートエンジンです。する だけで書いてあり、C のライブラリは要りません。テンプレートの文字列を読み、値を差し込んで文字列を返します。たとえば [suru-lang/http](https://github.com/suru-lang/http) で作る Web アプリの HTML の画面に使えます。

最初の計画は [#1](https://github.com/suru-lang/template/issues/1)、次の計画は [#5](https://github.com/suru-lang/template/issues/5) です。この版には両方の計画の全部(差し込み・注釈・繰り返し・条件・式・フィルター・ファイルと継承・挿入・自動エスケープ・空白の制御・テンプレートの中で決める名前・部品・行の整え・値で決めるテンプレートの名前)があります。

## 入れ方

[kumu](https://github.com/suru-lang/suru/blob/main/README_jp.md#プロジェクトを組むkumu) のプロジェクトで:

```sh
kumu 追加 github.com/suru-lang/template
```

## 使い方

```
「JSON」 を 読み込んで 使う
「雛形」 を 読み込んで 使う

挨拶表示する とは 手順
  値 とは 「{"客": {"名前": "花子"}, "品々": [{"名前": "りんご", "値段": 120}, {"名前": "みかん", "値段": 80}]}」 を JSON読取した 結果
  雛 とは 「{{ 客 の 名前 }}さん、いらっしゃいませ。今日のおすすめは{{ 品々 の 1番目 の 名前 }}({{ 品々.1.値段 }}円)です。」
  r とは 雛 を 値 で 雛形描画する
  もし r が
    s の 成功 ならば s を 表示する
    e の 失敗 ならば 「描画できません: 」 + e を 表示する

挨拶表示する
```

「花子さん、いらっしゃいませ。今日のおすすめはりんご(120円)です。」と表示します。例は [例/挨拶.suru](例/挨拶.suru) です。`「雛形」 を 読み込む` なら、`雛形内の雛形描画する` のように前置きを付けます。

| 呼び方 | 結果 |
|---|---|
| `t を 値 で 雛形描画する` | テンプレートの文字列 `t` に `値`(`JSON物`)の値を差し込んだ文字列。`（文字列 と 文字列） の 成否` |
| `t を 雛形解析する` | テンプレートを1回だけ読む。`（雛形 と 文字列） の 成否` |
| `g を 値 で 雛形適用する` | 読んだテンプレートに値を差し込む(同じものを何度も描くとき)。`（文字列 と 文字列） の 成否` |
| `t を 値 で 設定 に 雛形設定描画する` ・ `g を 値 で 設定 に 雛形設定適用する` | 設定(`雛形既定設定` と、それに足したもの)を使って同じことをする |
| `設定 に 名前 と 関数 を 雛形濾過追加する` | 自分のフィルターを足した設定(下を見てください) |
| `名前 を 値 で 雛形読込描画する` ・ `名前 を 値 で 設定 に 雛形設定読込描画する` | ファイルを読んで描く(`（文字列 と 文字列） の 成否` の動作)。継承・挿入で書いた名前のファイルも同じフォルダから読む |
| `設定 に 場所 を 雛形場所設定する` | フォルダ 場所 からファイルを読む設定 |
| `設定 に 名前 と 文字列 を 雛形部品追加する` | 継承・挿入で名前を書いて使えるテンプレートを足した設定 |
| `設定 に 真 を 雛形逃避設定する` | どのテンプレートでも `{{ }}` を HTML の逃がしにする設定(`偽` ならどれもしない) |
| `設定 に 真 を 雛形行整設定する` | `{% %}`・`{# #}` の後の改行と、行の頭からそれまでの空白を除く設定 |
| `t を 設定 で 雛形設定解析する` | 設定を使ってテンプレートを1回だけ読む(`雛形行整設定する` のため) |

テンプレートの書き方です。

| 書き方 | 意味 |
|---|---|
| `{{ 題 }}` | 名前 題 の値 |
| `{{ 客 の 名前 }}` ・ `{{ 客.名前 }}` | 客 のフィールド 名前 |
| `{{ 品々 の 2番目 }}` ・ `{{ 品々 の 2 }}` ・ `{{ 品々.2 }}` | 品々 の2番目の要素(位置は1から) |
| `{{ 「文字」 }}` ・ `{{ 3 }}` | 文字列や数をそのまま |
| `{# … #}` | 注釈(何も書かない) |
| `{% 品々 の それぞれ を 品 として %}` … `{% 以上 %}` | 品々 の要素ごとに繰り返す(`{% for 品 in 品々 %}` … `{% endfor %}`) |
| `{% 値段表 の それぞれ を 名 と 値 として %}` | 物の名前と値ごとに繰り返す(`{% for 名, 値 in 値段表 %}`) |
| `{% 空なら %}` | 繰り返しの中で、繰り返すものが無いときに書くもの(`{% else %}`) |
| `{{ 繰り返し の 番号 }}` | 繰り返しの中の、繰り返しの値(決めたことを見てください) |
| `{% もし 在庫 > 0 ならば %}` … `{% そうでなく もし 予約可 ならば %}` … `{% そうでなければ %}` … `{% 以上 %}` | 条件(`{% if 在庫 > 0 %}` … `{% elif 予約可 %}` … `{% else %}` … `{% endif %}`) |
| `{{ 値段 * 2 + 1 }}` ・ `{{ 名 + 「さん」 }}` | 式(決めたことを見てください) |
| `{{ 名 を 空白除去して 大文字にする }}` ・ `{{ 名 \| trim \| upper }}` | フィルター(下の表) |
| `{% 合計 とは 値段 * 2 %}` | まとまりの終わりまで使える名前を値に付ける(`{% set 合計 = 値段 * 2 %}`) |
| `{% 名 を 値 で 入力欄する とは %}` … `{% 以上 %}` | 部品(`{% macro 入力欄(名, 値) %}` … `{% endmacro %}`) |
| `{{ 「x」 を 「y」 で 入力欄する }}` ・ `{{ 線引する }}` | 部品を呼ぶ(`{{ 入力欄('x', 'y') }}` ・ `{{ 線引() }}`) |
| `{% 「部品.html」 を 取り込む %}` | 部品.html の部品を使う(`{% import "部品.html" %}`) |
| `{% 「土台.html」 を 継承する %}` | このテンプレートの区画で 土台.html を書く(`{% extends "土台.html" %}`) |
| `{% 区画 本文 %}` … `{% 以上 %}` | 子のテンプレートが置き換えられる区画(`{% block 本文 %}` … `{% endblock %}`) |
| `{{ 親区画 }}` | 区画の中で、親の同じ区画の中身(`{{ super() }}`) |
| `{% 「頭.html」 を 挿入する %}` | ここに 頭.html を同じ名前で書く(`{% include "頭.html" %}`) |
| `{% 頁型 を 継承する %}` ・ `{% 品 を 挿入する %}` | テンプレートの名前には、文字列になる式を書ける |
| `{%- … -%}` ・ `{{- … -}}` ・ `{#- … -#}` | `-` の側の前か後ろの空白と改行を除く |
| `{%+ … +%}` | `雛形行整設定する` のとき、`+` の側の前の空白か後ろの改行を残す |

フィルターです(どれも する の書き方と Jinja の書き方で書けます)。

| する | Jinja | 結果 |
|---|---|---|
| `x を 大文字にする` ・ `小文字にする` | `x \| upper` ・ `lower` | 大文字・小文字 |
| `x を 空白除去する` | `x \| trim` | 両端の空白を除いたもの |
| `x を 長さにする` | `x \| length`(`count`) | 文字列・リスト・物の長さ |
| `xs を 「、」 で 結合する` | `xs \| join("、")` | 要素をつないだもの |
| `s を 「,」 で 分割する` | `s \| split(",")` | 文字列のリスト |
| `s を 「a」 から 「b」 へ 置換する` | `s \| replace("a", "b")` | 「a」を「b」にしたもの |
| `x を 「なし」 で 既定にする` | `x \| default("なし")`(`d`) | x が無いか `無` なら「なし」 |
| `x を 逃避する` | `x \| escape`(`e`) | HTML の逃がし(`& < > " '`) |
| `xs を 整列する` ・ `逆順にする` | `xs \| sort` ・ `reverse` | 小さい順(数だけか文字列だけ)・逆の順 |
| `xs を 先頭にする` ・ `最後にする` | `xs \| first` ・ `last` | 最初・最後の要素(空なら `無`) |
| `x を 数値にする` ・ `整数にする` ・ `切捨する` | `x \| float` ・ `int` | 数(数か文字列から) |
| `x を 四捨五入する` | `x \| round` ・ `round(2)` | 四捨五入(小数第2位まで) |
| `x を 桁区切する` | | 「1,234,567」 |
| `x を 文字列化する` ・ `JSON文字列にする` | `x \| string` ・ `tojson` | `{{ }}` で書くときの文字列、JSON |
| `x を 生にする` | `x \| safe` | `{{ }}` を逃がすところでもそのまま書く |

## 決めたこと

1. **区切りは Jinja と同じ。** `{{ … }}` は値を書き、`{% … %}` は命令、`{# … #}` は注釈です。命令の言葉は日本語にし、Jinja の英語の言葉も別名として使えるようにします(`{% 品々 の それぞれ を 品 として %}` と `{% for 品 in 品々 %}`)。
2. **値は標準の `JSON`。** 差し込む値は `lib/JSON.suru` の `JSON物` なので、JSON のファイルから読んだものや HTTP で受け取ったものをそのまま渡せます。その項目が、テンプレートで使える名前です。
3. **描画は 成否 を返す純粋な関数。** テンプレートを読めないときや値が無いときは、「2行目: 「客」に「年」がありません」のように行の付いた `失敗` になります。`した 中身` で失敗をそのまま返せます。
4. **無い名前はエラー。** 定義されていない名前を何も書かない Jinja と違い、無い名前やフィールドはエラーにして、打ち間違いが見つかるようにします。無くてもよい値は、既定の値のフィルターで書けるようにします。
5. **値の書き方。** 文字列はそのまま、数は `文字列化する` と同じ(`120`・`80.5`)、真偽は `真`・`偽`、`JSON無` は何も書かず、リストと物は1行の JSON にします。
6. **「の」と「.」は同じ。** `客 の 名前` は する のフィールドの読み方、`客.名前` は Jinja の書き方です。その後の数や「N番目」は位置で、する の標準ライブラリと同じく1から数えます。
7. **文字列の中の閉じは数えない。** `{{ 「}}」 }}` の「」の中の 「}}」 は文字列の一部です。文字列の中の「」は、する と同じく入れ子として数えます。

8. **繰り返しは する と同じく読む。** `{% 品々 の それぞれ を 品 として %}` は する の `の それぞれ` の形で、`{% for 品 in 品々 %}` も同じです。`{% 以上 %}`(`{% 以上です %}`・`{% endfor %}` も)で終わります。付けた名前は繰り返しの中だけで見え、外の同じ名前を隠します。
9. **物は書いた順に繰り返す。** 名前を2つ書くと(`名 と 値 として`・`for 名, 値 in …`)、それぞれの項目の名前と値です。1つなら Jinja と同じく名前だけです。リストには名前を1つ書きます。
10. **繰り返しの値。** 繰り返しの中では `繰り返し`(`loop` も)に、`番号`(1から)・`長さ`・`最初である`・`最後である`・`残数`(残りの数)と、Jinja の `index`・`index0`・`length`・`first`・`last`・`revindex` があります。入れ子のときは一番内側の繰り返しのものです。
11. **空のとき。** 繰り返しの中の `{% 空なら %}`(`{% else %}` も)から後ろが、リストや物が空のときに書くものです。

12. **条件は する と同じく読む。** `{% もし 条件 ならば %}`・`{% そうでなく もし 条件 ならば %}`・`{% そうでなければ %}` は する の言葉で、`if`・`elif`・`else` も同じです。`{% 以上 %}`(`{% endif %}` も)で終わります。
13. **真になるものは Jinja と同じ。** `無`・`偽`・`0`・「」・空のリスト・空の物は偽で、ほかは真です。
14. **条件の中では無い名前は 無。** 条件の中では、無い名前・フィールド・位置はエラーにせず `無` にするので、`{% もし 客.住所 ならば %}` で有るかどうかを確かめられます。条件の外ではこれまでどおりエラーです。
15. **式。** 弱いものから順に、`または`・`or`、`かつ`・`and`、`not x` と `x でない`、比べる `=` `==` `が` `≠` `!=` `<` `>` `<=` `>=` `≦` `≧`(1つの式に1回)、`+` `-`、`*` `/` `%`、符号の `-` です。`( )` と `（ ）` でまとめます。`+` は数を足し、文字列をつなぎます。`<` などは数どうしと文字列どうしを比べます。ほかの組み合わせはエラーです。`真`・`偽`・`空`(空のリスト)・`無`(`true`・`false`・`null`・`none` も)は値です。

16. **フィルターは する の関数と同じく呼ぶ。** `{{ s を 「a」 から 「b」 へ 置換して 大文字にする }}` のように、値を「を」で、引数を助詞で(順は自由)渡し、「して」でつなぎます。呼び出しは式の中で一番弱いので、`{{ 「ab」 + 名 を 空白除去する }}` はつないだ文字列の空白を除きます。Jinja の `|` は Jinja と同じく強く結びつくので、`{{ 品々 | length > 2 }}` は長さを比べます。Jinja のフィルターの名前は する の名前になります。
17. **`既定にする` は無い名前も見る。** `既定にする`・`default` に渡す値は条件の中と同じく読むので、無い名前やフィールドはエラーでなく既定の値になります。
18. **自分のフィルターは する の関数。** `雛形濾過追加する` で足したフィルターは、値と引数のリスト(引数は で・から・へ・に・より の順か、`|` の後に書いた順)を受け取り、`値 の 成功` か `理由 の 失敗` を返します。失敗は行の付いたエラーになります。する の書き方で呼ぶには名前を「する」で終わらせます。`|` の後ならどんな名前でも使えます。
19. **Jinja の引用符の文字列。** テンプレートでは「…」のほか、Jinja の書き方のために `"…"`・`'…'` も書けます。

20. **ファイルは描く前に読む。** `雛形設定読込描画する` はファイルを読み、その中の `継承する`・`挿入する` で書いた名前のファイル(とその中のもの)を設定のフォルダから読んでから描きます。文字列で書いた名前(「土台.html」)は描く前に分かります。値で決める名前は、下の「値で決めるテンプレートの名前」を見てください。ファイルが無ければ「「無い.html」というテンプレートのファイル(画面/無い.html)を読めません」の `失敗` です。
21. **継承は Jinja と同じ。** `継承する` のあるテンプレートは親を書き、親の同じ名前の区画を自分の区画で置き換えます。区画の外に書いたものは書きません。親がさらに継承してもよく、`{{ 親区画 }}` は次の親の中身を書きます。継承しなければ、区画は自分の中身を書きます。
22. **挿入は同じ名前を見る。** 挿入したテンプレートは、その場所の名前(繰り返しの中なら繰り返しの名前も)で描きます。その中の区画はそのテンプレートのものです。
23. **エラーにはテンプレートの名前を付ける。** 名前で使ったテンプレートの中のエラーは、「「土台.html」の3行目: …」のように名前から始まります。直接でも間接でも自分を継承・挿入するテンプレートは「…の継承か挿入が輪になっています」のエラーです。
24. **テンプレートは文字列でも渡せる。** `雛形部品追加する` で名前の付いたテンプレートを設定に足すと、ファイルなしでも `雛形設定描画する` や試験で継承・挿入が使えます。

25. **HTML のテンプレートは自分で逃がす。** 名前が `.html`・`.htm`・`.xml` で終わる(大文字小文字は問わない)テンプレートでは、`{{ }}` は値を HTML の逃がし(`& < > " '`)にして書くので、人から受け取った値でタグを足されません。名前のない文字列のテンプレートや `.txt` などは、値をそのまま書きます。`雛形逃避設定する` に `真` を渡すとどのテンプレートでも逃がし、`偽` ならどれも逃がしません。
26. **`生にする` は安全な値の印。** `生にする`・`safe` はそのまま書く値にします。`逃避する`・`escape` は逃がした値に同じ印を付けるので、2回逃がしません。ほかのフィルターは文字列を受け取り、ふつうの値に戻します。

27. **空白の制御は Jinja と同じ。** 区切りのすぐ内側の `-`(`{%-`・`-%}`・`{{-`・`-}}`・`{#-`・`-#}`)は、その側の文字の空白・タブ・改行を除きます。`-` の前に空白がある `{{ -x }}` は、これまでどおり負の数です。

28. **名前は する と同じ形で決める。** `{% 合計 とは 値段 * 2 %}` は する の定義の形で、`{% set 合計 = 値段 * 2 %}` も同じです。名前は、そこから入っているまとまり(テンプレート・繰り返しの本体・枝・区画)の終わりまで見え、外の同じ名前を隠します。Jinja と違い、`もし` の枝で決めた名前は `{% 以上 %}` の後では見えないので、枝の前で決めます。決める前に使った名前は、ほかの無い名前と同じくエラーです。

29. **部品は する の関数と同じ形で書く。** `{% 名 を 値 で 入力欄する とは %}` … `{% 以上 %}` は する の関数の定義と同じ形で部品を決め、フィルターと同じく `{{ 「x」 を 「y」 で 入力欄する }}` で呼びます。値は助詞で名前に結び付くので、引数の順は問いません。引数のない部品は `{% 線引する とは %}` で、名前だけの `{{ 線引する }}` で呼びます。なので、する で終わる名前だけを書くと、値ではなく呼び出しです。Jinja の `{% macro 入力欄(名, 値) %}` も同じで、`{{ 入力欄('x', 'y') }}` のように書いた順に値を渡します。値の数は合わせます。
30. **部品は引数と、決めたところの名前を見る。** `とは` で決めた名前と同じく、部品はそこからまとまりの終わりまで使え、自分の中でも使えるので自分を呼べます。本体は引数と、決めたところの名前を見て、呼んだところの名前は見ません。書いたものは生です(本体の中で逃がし、もう一度は逃がしません)。
31. **`取り込む` はテンプレートの部品を全部使えるようにする。** `{% 「部品.html」 を 取り込む %}`(`{% import "部品.html" %}`)は、部品.html の一番外の部品をそこから使えるようにし、部品.html の中身は何も書きません。Jinja の `import … as` と違い、部品の前に名前を付けません。ファイルは継承・挿入と同じく、描く前に読みます。

32. **行の整えは Jinja の `trim_blocks` と `lstrip_blocks` を合わせたもの。** `雛形行整設定する` に `真` を渡すと、`{% %}`・`{# #}` のすぐ後の改行と、行の頭から命令までの空白・タブを除くので、1行に命令だけを書いても空の行が残りません。`{{ }}` は変えません。`{%+` は前の空白を、`+%}` は後ろの改行を残します。既定は切です。整えはテンプレートを読むときにするので、`雛形設定描画する`・`雛形設定読込描画する` と、継承・挿入・`取り込む` で使うテンプレートは設定に従い、`雛形解析する` は従いません。設定を使って1回だけ読むときは `雛形設定解析する` を使います。

33. **値で決めるテンプレートの名前。** `継承する`・`挿入する`・`取り込む`(と `extends`・`include`・`import`)には、`{% 頁型 を 継承する %}` や `{% 「部品/」 + 種類 + 「.html」 を 挿入する %}` のように式を書けます。値は文字列にします。`継承する` の前の一番外で `とは` で決めた名前と部品は、その名前の式でも使えます。ファイルでは、`雛形設定読込描画する` は文字列で書いた名前を先に読み、値で決めた名前がまだ読んでいないものなら、そのファイルを読んで描き直すので、使うファイルだけを読みます。

34. **文字は1文字ずつではなく、まとめて読む。** テンプレートを `{` ごとに分け、その間の文字はまとめたまま扱い、命令だけを1文字ずつ読みます。大きなテンプレートでもメモリをあまり使いません(125 KB の文字を約 60 MB で描けます。前はメモリが足りなくなっていました)。`例/大きさ.suru` は約5万8千文字・命令900個のテンプレートを `suru` で約5秒(うち2秒は立ち上がり)で描きます。

## API ドキュメント

API ドキュメントは `雛形.suru` の注釈から作ります。ファイルの頭の注釈と、公開の定義のすぐ上の注釈で、英語で書いています。

```sh
kumu 文書                                                            # docs/api/雛形.md を書く
pip install -r docs/requirements.txt && sphinx-build docs docs/_build   # docs/_build に HTML
```

`docs/` と `.readthedocs.yaml` は `kumu 文書 --雛形`(する 0.11.0 以上)で書きました。Read the Docs はビルドのたびに kumu 0.11.0 を取ってきて `kumu 文書 --出力 docs/api` を動かしてから Sphinx を動かすので、作ったページはコミットしません。エディタのホバーにも同じ説明が出ます。
